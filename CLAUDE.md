## Overview

This is a personal academic website, hand-built as a static site: plain HTML/CSS output generated by a small
TypeScript build script, no Jekyll and no frontend framework. It's deployed to GitHub Pages via GitHub Actions.

### Commands

```bash
npm install       # install dependencies
npm run build     # compile client TS + generate the site into dist/
npm run serve     # serve dist/ locally at http://localhost:8080
npm run format    # prettier --write
```

There are no unit tests. "Testing" a change means running `npm run build`, serving `dist/`, and checking the
affected page(s) plus the dark-mode toggle in a browser.

### Architecture

- **Content lives in `content/`** and is what you edit day-to-day:
  - `content/site.yml` — site-wide config: name, contact links, nav menu.
  - `content/pages/*.md` — markdown + frontmatter for the about/home, publications, and repositories pages.
  - `content/posts/*.md` — blog posts, filename format `YYYY-MM-DD-slug.md`, frontmatter: `title`, `date`,
    `description`, `tags`.
  - `content/publications.bib` — BibTeX bibliography; supports `pdf`, `code`, and `doi` fields per entry.
  - `content/coauthors.yml` — maps a coauthor's last name to profile URLs so their name gets linked on the
    publications page.
  - `content/repositories.yml` — `github_users` / `github_repos` lists rendered on the repositories page.
- **`src/build/`** is the static site generator (plain Node/TypeScript, compiled by `tsc` then run with `node`):
  - `build.ts` is the entry point — reads everything under `content/`, renders each page, writes `dist/`.
  - `markdown.ts` renders Markdown via `marked`, pre-rendering `$...$` / `$$...$$` math to static KaTeX HTML so
    posts don't need a client-side math library.
  - `bibtex.ts` is a small hand-rolled BibTeX parser (handles brace-nested values).
  - `publications.ts` / `repositories.ts` render those content types to HTML; `templates.ts` holds the shared
    page layout (nav, footer, dark-mode toggle markup).
- **`src/client/theme-toggle.ts`** is the only client-side script — compiled by `tsc` straight to
  `assets/js/theme-toggle.js` (no bundler). It flips a `data-theme` attribute on `<html>` and persists the choice
  in `localStorage`; an inline snippet in `templates.ts` applies the stored theme before first paint to avoid a
  flash of the wrong theme.
- **`styles/style.css`** is the single stylesheet: CSS custom properties for light/dark, `prefers-color-scheme`
  as the default with `[data-theme]` as a manual override.
- **`assets/`** holds the few static files the build copies verbatim (currently just the profile photo and the
  compiled theme-toggle script).
- **`dist/`** is the build output — gitignored, regenerated by `npm run build`, deployed by
  `.github/workflows/deploy.yml`.

### Adding content

- New blog post: add `content/posts/YYYY-MM-DD-slug.md` with the frontmatter shown above.
- New publication: add a BibTeX entry to `content/publications.bib`.
- Editing the bio, nav, or contact links: `content/pages/about.md` and `content/site.yml`.
