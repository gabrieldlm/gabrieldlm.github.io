# gabrieldlm.github.io

Personal academic website. Hand-built static site — plain HTML/CSS generated by a small TypeScript build script,
no framework. Content is authored in Markdown, YAML, and BibTeX under `content/`.

## Development

```bash
npm install
npm run build   # generate the site into dist/
npm run serve   # serve dist/ at http://localhost:8080
```

See [CLAUDE.md](CLAUDE.md) for an overview of the build architecture and where to edit content.

## Deployment

Pushes to `main` build the site and publish `dist/` to the `gh-pages` branch via
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
